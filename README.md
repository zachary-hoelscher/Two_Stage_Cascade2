# Two_Stage_Cascade2
Here we consider a two-stage dark matter decay chain (A->2B), where the decay is triggered by spontaneous symmetry breaking in the dark sector. Here A has an equation of state parameter of zero, whereas B has a varying and negative equation of state parameter. This results in a larger late-time value for the Hubble parameter, allowing for partial alleviation of the Hubble tension. Note that A and B are a subcomponent of the dark matter. Here we show that the expansion history agrees (to a good approximation) with that found from a closely related model in the literature, given appropriate choices of parameters. This existing model did not posit a specific microphysical mechanism, which we consider here.

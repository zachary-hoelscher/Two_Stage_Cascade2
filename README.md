# Two_Stage_Cascade2
Here we consider a two-stage dark matter decay chain (A->2B), where the decay is triggered by spontaneous symmetry breaking in the dark sector. Here A does not couple to dark energy, whereas B does couple to dark energy. We find that this allows for a larger late-time value for the Hubble parameter, where the expansion history can be mapped onto an existing model at the background level, to a good approximation. Note that A and B are a subcomponent of the dark matter.

We also consider a case where B has a varying and negative equation of state parameter, where we borrow the phenomenological model used by Naidoo et al.
